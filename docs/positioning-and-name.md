# Positioning and name

## Positioning

This project is an opinionated reference implementation shaped by real use of
Cursor, Claude Code, and Codex. It is for developers who want to maintain a
small, field-tested personal skill library across agent hosts.

Its value is the integrated example:

- workflows extracted from repeated engineering work;
- one public-safe canonical layer;
- host adapters instead of divergent skill copies;
- explicit analysis and mutation boundaries;
- evidence-based verification and maintenance;
- a cloneable setup with non-destructive installation.

It does not claim to invent skill installation, validation, evaluation, usage
analytics, or skill-library maintenance. Existing projects already address
those categories, including:

- [SkillOps](https://github.com/Hik289/SkillOps)
- [Agent Skill Eval](https://github.com/aws-samples/sample-agent-skill-eval)
- [Skills Manager](https://github.com/xingkongliang/skills-manager)
- [AIUsage](https://github.com/sylearn/AIUsage)
- [AgentSync](https://github.com/dallay/agentsync)
- [skills.sh](https://www.skills.sh/)

## Naming criteria

The name should communicate curation and real use without implying a new
framework or universal platform. It should remain useful if more agent hosts are
added later.

| Candidate | Strength | Limitation |
| --- | --- | --- |
| `agent-skill-garden` | Expresses grow, observe, prune, and share | Metaphorical; needs a clear tagline |
| `personal-ai-workflows` | Direct and easy to understand | Broad and less memorable |
| `practical-agent-workflows` | Emphasizes real use | Does not foreground skills |
| `field-tested-agent-skills` | Strong portfolio claim | Long and sounds like only a catalog |
| `agent-workflow-garden` | Leaves room beyond skills | Less searchable for Agent Skills users |

## Recommendation

Use **`agent-skill-garden`** with this tagline:

> A field-tested skill garden shaped by real workflows across Cursor, Claude Code, and Codex.

The garden metaphor matches the operating loop: useful workflows are cultivated,
weak triggers are tuned, overlap is merged, and unused material is pruned. The
tagline keeps the otherwise metaphorical name concrete.

The public repository is
[changbaebang/agent-skill-garden](https://github.com/changbaebang/agent-skill-garden).
